# Locked Research Plan

Status: locked on 2026-07-29. Changes require an explicit amendment documenting
the reason, date, and whether any results had already been observed.

## Research question

Does Whisper-small LoRA adaptation improve transcription of financial-domain
terms without materially degrading common-language recognition?

## Primary experiment

- Base model: `openai/whisper-small`.
- Adaptation: LoRA with the committed financial configuration.
- Trials: five independent seeds: 11, 22, 33, 44, and 55.
- Data: generated financial speech with train, validation, and test partitions
  that are disjoint by TTS voice and sentence template family.
- The test partition is immutable and is never used for early stopping, model
  selection, threshold selection, or configuration choice.
- Signal construction uses training data only. Validation selects checkpoints.
  Test evaluation occurs after training.
- Primary metric: corpus domain-term WER.
- Secondary metrics: corpus overall WER and corpus common-term WER.
- Uncertainty: 95% percentile confidence intervals from 10,000 paired,
  utterance-cluster bootstrap resamples. Five-trial summaries also report the
  distribution across seeds.
- Comparison: each adapted model is paired with the frozen base model on the
  identical test utterances.

## Normalization

WER uses one committed normalization pipeline for references and hypotheses:
Unicode normalization, lowercase, punctuation removal, and whitespace
collapse. Domain terms are matched after the same normalization.

## Leakage controls

- No voice appears in more than one partition.
- No template family appears in more than one partition.
- Audio-content hashes and normalized transcript hashes are checked across
  partitions.
- Dataset manifests record source, voice, template family, term, and stable ID.
- Failed audio loads or inference failures abort the run; they are never
  silently converted to empty predictions.

## Reproducibility and provenance

Every run records the Git commit, dirty-worktree flag, exact arguments,
configuration hash, dataset hashes, package versions, Python/PyTorch/CUDA
versions, device, seed, timestamps, predictions, and metrics. Numerical tables
in documentation must be generated from these artifacts by a named script.

## Interpretation boundary

The financial test audio is generated by TTS. TTS-on-TTS performance is
optimistic and is not evidence of earnings-call performance. No estimate for
real earnings-call WER will be reported without a licensed, manually verified,
speaker-disjoint real-audio evaluation set.

## Acceptance criteria

A headline improvement is publishable only if:

1. all five trials complete under this plan;
2. the paired 95% CI for the domain-WER difference excludes zero;
3. all metrics carry `N_trials=5` and a 95% CI;
4. common-term and overall WER are reported beside domain-term WER;
5. all numbers regenerate from committed result artifacts; and
6. the TTS-only external-validity limitation is displayed with the result.

## Out of scope

The experimental neural codec is not part of this ASR claim and must not appear
in the primary research narrative until it has a separate locked protocol,
baselines, bitrate accounting, validation data, and perceptual evaluation.
